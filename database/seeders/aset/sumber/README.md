# Aset sumber (hak cipta penyusun)

PDF di folder ini dihasilkan dari `E-Model PING_Revisi 1.pdf` (121 halaman) dengan
`scripts/sumber/pisah_pdf.py`. `manifest.json` mencatat SHA-256 PDF sumber dan setiap
potongan, rentang halaman PDF/cetak, serta catatan halaman bersama (Bab VII/VIII di
halaman 102; Bab IX dan "Pesan untuk Guru PAUD" di halaman 118). Pemotongan di tengah
halaman tidak dilakukan.

Materi adalah hak cipta penyusun dan tidak termasuk lisensi kode (MIT).
Metadata penulis pada PDF asli (berisi alamat surel pribadi) tidak ikut disalin.
