## Walkthrough browser (pane browser aplikasi desktop, http://127.0.0.1:8000)

Dilakukan: beranda (tema gelap & terang), Bab IV + daftar isi, preferensi ukuran huruf bertahan setelah muat ulang (bug ditemukan & diperbaiki: variabel CSS tertimpa), penampil PDF (Range 206 terlihat di jaringan, pindah halaman), pencarian "kontrol diri", kirim pesan kontak, login admin dengan captcha, dashboard + grafik demo, editor Tiptap subbab, tampilan ponsel 375 px tanpa gulir horizontal. Mode buku (flipbook) `/dokumen/1/baca`: sampul di kanan lalu sebaran 2–3, 4–5, …; balik lewat tombol, panah kiri/kanan, Home/End, klik sisi halaman, geser, dan slider; ponsel 375 px satu halaman tanpa gulir horizontal; pilihan "Mode standar" tersimpan setelah muat ulang; konsol tanpa galat. Animasi 3D diperiksa dengan membekukan lembar pada sudut tertentu karena pane membatasi `requestAnimationFrame` (~2 fps); tombol layar penuh belum diklik manual. Konsol bersih setelah perbaikan (sebelumnya: React #419 dari Suspense malas saat SSR → diganti `KlienSaja`; `usePage` di luar konteks saat SSR → hook flash dipindah ke layout).
